        What just happened

        1. The page created a RoadRestriction entity (datamodels.jp) in GeonicDB, an NGSI-LD context broker.
        2. A subscription notified the bridge. It sent the entity, as it is, to Pointsman: the profile reads the attributes it needs, no mapping code.
        3. Pointsman asked the model four typed questions and turned the answers into an action with the city's rules. The bridge wrote the result back to the entity (check) and as a Decision entity, so other FIWARE apps can subscribe to it.
        4. Reports that need a person became GitHub issues. A member resolves one with /publish or /reject; the answer goes back to Pointsman as feedback.
